# Карта годового плана

Источник — сохранённый `assets/annual-plan-template.docx`, предоставленный пользователем как «Годовой план ДО Шаблон    .docx». Это карта конкретного образца, а не утверждение об обязательности формы.

Подробность заполнения определяет также [content-requirements.md](content-requirements.md) по комментариям пользователя. Для подраздела 2.8 комментарии расширяют перечень просмотров на каждый педсовет, включая №1; добавляй строки в существующую таблицу, сохраняя колонки.

Таблицы результата сохраняют структуру образца, но оформляются без заливки, шрифтом Times New Roman 12 пт. Заголовки и содержание переводятся на казахский по умолчанию, русский или английский по выбору руководителя. Все сведения о сотрудниках и детях — только количества и сводные количественные показатели; ФИО и другие персональные сведения не запрашиваются и не включаются. Ответственные обозначаются по должности или службе.

## Вводные части

**I. Визитная карточка дошкольной организации**: полное наименование; юридический адрес; тип ДО, количество групп и детей; режим работы; наличие кабинетов.

**II. Характеристика кадрового состава**:

- Общее количество работников и педагогический состав.
- Количество педагогов по стажу: менее 3 лет; от 3–7 лет; от 8–16 лет; от 17–20 лет; свыше 20 лет. Уточняй только сводные количества по диапазонам; индивидуальный стаж и списки работников не запрашивай.
- Образование: высшее и (или) послевузовское педагогическое, из них с высшим профессиональным; техническое или профессиональное педагогическое.
- Категории: педагог-мастер, педагог-исследователь, педагог-эксперт, педагог-модератор, педагог.
- Повышение квалификации: обучаются в вузах; проходят курсовую подготовку.

**III. Методическая тема, годовые задачи**: образец прямо связывает годовые задачи с анализом работы за прошедший учебный год.

## Раздел 1. Охрана здоровья и обеспечение здорового образа жизни воспитанников

Поле «Цель» и направления:

1.1. Улучшение качества медицинского обслуживания.

1.2. Система рационального питания.

1.3. Система физкультурно-оздоровительных мероприятий.

1.4. Система психологической службы.

1.5. Система работы по обеспечению охраны труда и безопасности жизнедеятельности детей и сотрудников.

Смысловые колонки: «№ п/п», «Содержание деятельности», «Сроки», «Ответственные», «Где рассматривается». В XML исходника есть дополнительные технические колонки и объединённые ячейки: не считать их отдельными содержательными полями.

2.2. Семинары.

2.3. Педагогические часы.

2.4. Методические часы.

2.5. Работа СППС, педагогический консилиум. Использовать реальную организацию службы сопровождения; не предполагать наличие специалистов по одному заголовку.

2.6. Консультации: 2.6.1 для всех педагогов; 2.6.2 индивидуальные.

2.7. Проекты.

2.8. Открытые просмотры ОД к педсоветам №2, №3, №4, №5; к №5 в образце указаны итоговые занятия и выпуск детей в школу.

Для 2.2–2.8 общие смысловые колонки: содержание деятельности, сроки, ответственные. Несколько подразделов находятся внутри одной таблицы.

2.9. Мероприятия с детьми.

2.10. Совместная творческая деятельность: педагоги — дети — родители.

Колонки 2.9–2.10: вид деятельности, тематика, дата проведения, ответственные.

2.11. Работа с кадрами.

2.12. Подготовка к аттестации, выполнение рекомендаций по аттестации.

2.13. Работа с молодыми специалистами.

2.14. Организация и содержание работы методического кабинета.

Для 2.11–2.14: цель; № п/п, содержание деятельности, сроки, ответственные, где рассматривается.

## Работа с отсутствующим направлением

Если нет молодых специалистов, аттестации или другого основания для мероприятий, сохраняй соответствующий подраздел и отражай подтверждённую неприменимость на выбранный год. Если сведений нет, оставляй поле для уточнения. Не создавай фиктивное мероприятие ради заполнения таблицы.
