# Basshy BilimAI Balabaksha

Плагин для руководителей дошкольных организаций Казахстана. Версия: **1.0.11**.

Мектепке дейінгі ұйым басшысының құжаттарын кірістірілген үлгілер негізінде дайындайды: үш жылдық даму бағдарламасы, жылдық жоспар және ай не апта циклограммасы. Нәтижелер өңделетін DOCX түрінде беріледі.

## Навыки

- Даму бағдарламасы / Программа развития (`do-development-program`).
- Жылдық жоспар / Годовой план (`do-annual-plan`).
- Іс әрекет циклограммасы / Циклограмма деятельности (`do-head-cyclogram`).

В комплект входят инструкции навыков, исходные методические документы, шаблоны Word, программы PDF, текстовые извлечения и логотипы. Утверждённое вступительное сообщение сохранено в каждом навыке.

## Структура репозитория

```text
.agents/plugins/marketplace.json
plugins/basshy-bilimai-balabaksha/
  plugin.json
  .codex-plugin/plugin.json
  assets/
  skills/
```

Техническое имя плагина и маркетплейса: `basshy-bilimai-balabaksha`.
Отображаемое название: **Basshy BilimAI Balabaksha**.

## Публикация в GitHub

Распакуйте архив и загрузите содержимое его основной папки в корень репозитория. Включите скрытую папку `.agents` и вложенную папку `.codex-plugin`. Не добавляйте дополнительный уровень папок между корнем репозитория и `.agents`.

## Подключение маркетплейса

В каталоге плагинов выберите «Добавить маркетплейс» и укажите URL созданного репозитория GitHub. Либо выполните команду, заменив `OWNER/REPOSITORY` фактическим адресом:

```shell
codex plugin marketplace add OWNER/REPOSITORY
```

После подключения откройте источник **Basshy BilimAI Balabaksha** в каталоге плагинов и установите плагин. При необходимости перезапустите приложение.

Для локального подключения используйте абсолютный путь к распакованной основной папке:

```shell
codex plugin marketplace add "PATH_TO_EXTRACTED_MARKETPLACE"
```

Папка `plugins/basshy-bilimai-balabaksha` содержит самостоятельный пакет плагина. Файл `.agents/plugins/marketplace.json` связывает его с маркетплейсом через относительный путь; абсолютные пути к компьютеру автора не требуются.
